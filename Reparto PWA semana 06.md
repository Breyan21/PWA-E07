ESTRATEGIA DE ARQUITECTURA PARA EL INCREMENTO (SEMANA 6) El objetivo de esta semana es dotar a la PWA de capacidades nativas y notificaciones manteniendo el principio de permisos mínimos (least privilege), acción explícita del usuario y fallback funcional obligatorio: 1. Evidencia Visual (Cámara): Captura de evidencia mediante MediaDevices.getUserMedia, liberando los recursos de hardware (tracks) tras el uso, con fallback a <input type="file" capture> o datos sintéticos si el permiso es denegado o no hay soporte. 2. Contexto Espacial (Geolocalización): Adquisición de coordenadas bajo demanda mediante Geolocation.getCurrentPosition respetando la minimización de datos (sin rastreo continuo invasivo), con fallback a selección manual de laboratorio sintético si el usuario declina el permiso. 3. Alertas de Cambio (Notificaciones): Solicitud contextual de permisos de notificación en el navegador con despacho de avisos de estado, y fallback in-app (banner/toast en interfaz) si el permiso es rechazado o no existe la API. 4. Verificación y Garantía de Privacidad: Suite automatizada de pruebas deterministas que valide la activación de fallbacks y un reporte formal de ingeniería sobre el uso ético y seguro de las APIs del dispositivo. 2.
